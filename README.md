# 서울 최근 3년 일평균기온의 계절 패턴과 급격한 기온 변화 분석

## 프로젝트 개요

- 코디세이 AI 응용 M1 「AI 데이터 분석: 데이터 기반 트렌드 분석」 과제다.
- 서울 최근 3년 일평균기온의 계절 패턴과 단기 기온 변화를 분석한다.
- 장기적인 기후변화를 증명하기 위한 분석은 아니다.

## 분석 질문

1. 최근 3년 서울의 일평균기온에는 어떤 계절적 패턴이 반복되는가?
2. 전날과 비교해 기온이 급격하게 변한 날은 언제였는가?
3. 월별 평균기온과 기온 변동성은 어떻게 다른가?

## 데이터

- 출처: 기상청 기상자료개방포털 종관기상관측(ASOS)
- 관측지점: 서울(108)
- 기간: 2023-10-01 ~ 2026-09-30
- 데이터 수: 1,096일
- 원본 파일: `data/seoul_daily_temperature_2023_2026.csv`
- 원본 CSV 인코딩: EUC-KR
- 사용 변수: 일시, 평균기온(°C)

데이터는 사용자가 기상자료개방포털에서 직접 내려받았다. 데이터 이용·재배포 시에는 기상청/공공데이터의 해당 이용정책을 확인해야 한다.

## 사용한 분석 방법

- **7일 이동평균:** 날짜를 중심으로 7일의 기온을 평균하여 짧은 기간의 흐름을 살펴본다.
- **30일 이동평균:** 날짜를 중심으로 30일의 기온을 평균하여 더 긴 기간의 흐름을 살펴본다.
- **전일 대비 평균기온 변화량:** 오늘의 일평균기온에서 전날의 일평균기온을 뺀다.
- **월별 평균:** 3년 전체 데이터를 1월~12월로 묶어 평균기온을 계산한다.
- **월별 표준편차:** 같은 월별 데이터가 평균 주변에 얼마나 퍼져 있는지 계산한다.
- **IQR 기반 이상치 후보 확인:** 가운데 50%의 기온 범위를 이용해 통계적 이상치 후보를 확인한다. 관측 극값을 자동으로 삭제하지 않는다.

급격한 변화 기준은 `|전일 대비 평균기온 변화량| >= 5.0°C`다. 절대 변화량의 95백분위수 약 4.93°C를 참고해 설정한 분석용 기준이며, 공식적인 기상학적 극단기온 기준은 아니다.

현재 프로젝트의 `.venv`에서 직접 확인한 버전이다.

| 항목 | 버전 |
|---|---|
| Python | 3.12.14 |
| pandas | 3.0.6 |
| matplotlib | 3.11.2 |

`requirements.txt`에는 직접 사용하는 pandas와 matplotlib의 버전만 고정했다. 재현 시에는 위 Python 버전을 사용한다.

## 실행 방법

macOS/Linux 터미널에서 아래 순서로 실행한다. 먼저 Python 3.12.14가 설치되어 있는지 `python3 --version`으로 확인한다.

1. 프로젝트 폴더를 준비하고 이동한다. 저장소가 공개된 뒤에는 아래 명령의 `<저장소 URL>`을 실제 주소로 바꾸어 실행한다. 현재는 저장소 URL이 정해지지 않았다. 이미 프로젝트 폴더가 있다면 clone을 생략하고 해당 폴더로 이동한다.

   ```bash
   git clone <저장소 URL> codyssey-m1-weather-analysis
   cd codyssey-m1-weather-analysis
   ```

2. 프로젝트 루트에서 가상환경을 생성한다. 이미 `.venv`가 있으면 이 단계를 생략한다.

   ```bash
   python3 -m venv .venv
   ```

3. 가상환경을 활성화한다.

   ```bash
   source .venv/bin/activate
   ```

4. 필요한 패키지를 설치한다.

   ```bash
   python -m pip install -r requirements.txt
   ```

5. 분석 코드를 실행한다.

   ```bash
   python analysis.py
   ```

실행하면 데이터 품질 확인과 분석 결과가 터미널에 출력되고, `figures/` 아래에 그래프 3개가 생성된다. 같은 이름의 그래프가 이미 있으면 다시 저장된다. CSV를 읽는 경로가 프로젝트 루트를 기준으로 하므로 반드시 `analysis.py`가 있는 폴더에서 실행한다.

현재 코드의 터미널 요약에는 36개 연월별 통계도 포함된다. 보고서의 Q1·Q3 결과는 그래프 3에서 사용하는 방식과 동일하게 3년 전체를 1월~12월로 묶은 통계다. 실행 코드는 보고서나 AI 사용 로그를 자동으로 작성하지 않는다.

## 주요 결과

- 계절 패턴: 약 1년 주기의 상승·하락이 3회 관찰됐다. 월별 평균기온은 8월 28.56°C로 가장 높고, 1월 -1.51°C로 가장 낮았다. 차이는 30.07°C다.
- 급격한 변화: 유효 변화량 1,095개 중 절대 변화량 5.0°C 이상은 55일(5.02%)이었다. 최대 하락은 2023-11-24의 -11.4°C, 최대 상승은 2026-01-15의 +8.0°C였다.
- 월별 변동성: 표준편차는 11월 약 5.53°C로 가장 크고, 8월 약 1.94°C로 가장 작았다. 반올림 전 값으로 계산한 차이는 3.58°C다.
